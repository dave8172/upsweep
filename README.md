# upsweep has moved

**upsweep now lives in [dave8172/skills](https://github.com/dave8172/skills/tree/main/skills/upsweep)**, together with other agent skills. This repo is archived and no longer updated.

Install the current version:

```
npx skills add dave8172/skills --skill upsweep
```

Claude Code plugin: `/plugin install upsweep --marketplace dave8172/skills`.

If you installed from this repo before, remove that copy (`npx skills remove upsweep`) and install from the new one to keep getting rule updates and fixes.
